# Offer 评估与薪资谈判

维护 `~/project/AI/job-hunt/offers.md`。核心信念：**谈判筹码不来自口才，来自替代选项**（见 job-pipeline 的 ≥3 活进程原则）。

## 总包拆解公式

```
年总包 = 月base × 薪数 + 签字费 + 期权/RSU折现 + 补贴
```

- 期权/RSU 按保守折现：上市公司 70%、D 轮后 30%、早期 0-10%
- **决策只看 cash 下限**（base×薪数+签字费），浮动部分当 bonus，不给它投票权
- 追问薪资结构：base / 绩效 / 补贴各占多少？绩效大部分人拿几折？年终奖写入 offer 吗？

## Offer 对比维度（offers.md 表格列）

总包cash / base 城市（一线 vs 长沙做生活成本修正，但记住用户要钱多，城市修正只影响生活质量评估不影响排序主键）/ **双休真实性** / **风气评级（来自 job-culture-vet）** / 业务前景 / 试用期折扣 / 五险一金基数 / 通勤

硬线回顾：钱多 + 双休 + 风气正常，三条不满足一条就准备 walk away。

## 谈判原则

1. **永不先报数**。被问期望 → 「想先了解下这个岗位的带宽是多少？」
2. 被逼报数 → 当前总包 +30% 为底，报带宽上沿；只有口头数没有书面时坚持不确认
3. **多 offer 是唯一硬杠杆**：如实告知「另有流程在终面」——这是事实陈述不是虚张声势
4. HR 压价应对：
   - 「预算有限」→ 问签字费、入职早调薪（3-6 个月重评）、职级上浮
   - 「别家 offer 到手了吗」→ 「有两家在最终阶段，我在综合评估」
   - 「先接了再谈」→ 永不。口头承诺 HR 会离职，书面不会
5. **一次谈个大数，不挤牙膏**：把 base、签字费、入职时间打包谈，谈完就定
6. 所有条款落到书面：薪资结构、试用期工资、调薪窗口、年终奖条件

## 场景脚本

**拿到口头 offer 第一时间回复**（不接不拒，先拖时间拉齐信息）：

> 非常感谢，这个机会我很认真对待。请把完整的薪资结构（base/薪数/绩效/签字费/期权）发我书面包，我需要 X 天时间做最终决定，X 日前给您确定答复。

（X = 3-14 天，视管道里其他进程离出结果多远——这是给其他公司施压加速的标准操作）

**比价还价**（手握另一个 offer 时）：

> 我很想来贵司，但手上有另一个 offer 总包高 X%。如果贵司能做到 [具体数字/签字费]，我今天就拒掉对方。

**礼貌拖 deadline**（其他进程还没走完）：

> 我对贵司的意向是第一位的，另有流程承诺本周出结果，出于对两边都负责，希望宽限到 X 日。

## 决策输出

offers.md 汇总对比表 + 一段建议：主推哪个、为什么、接了之后先做什么（书面确认→背景调查准备→入职时间谈判）。签字前最后跑一次 `job-culture-vet` 的最新舆情复查——**风气是唯一在签字前还要再验一次的项**。
