# 公司风气尽调

**为什么是硬性环节**：候选人亲历现公司（长沙数字马力）的办公室不当行为丑闻，对风气零容忍。尽调不是锦上添花，是和薪资同级的录取条件。

输入：公司名（+部门/业务线如有）。输出：`~/project/AI/job-hunt/culture-vet/<公司>.md`，结构化报告 + A/B/C/D 评级。

## 四个尽调维度

**1. 制度性**
- 大小周？996 是否常态化？加班有无调休/加班费？
- 试用期折扣比例、五险一金缴纳基数（足额还是最低）
- 薪资结构里浮动占比（浮动 >30% 视为变相降薪风险）

**2. 风气前科（重点，候选人的核心关切）**
- 搜索组合词：「公司名 + 骚扰 / 摸 / 猥亵 / 通报 / 开除 / 潜规则 / 办公室 事件」
- 「公司名 + 裁员 / 欠薪 / 仲裁」
- 渠道：新闻/公众号通报、裁判文书网（劳动纠纷、侵权纠纷）、脉脉职言、小红书、知乎
- 查该公司是否有过公开的骚扰通报或诉讼——**有实锤前科的，无论 offer 多好，直接 D 级**

**3. 管理风格**
- 末位淘汰？日报周报形式主义？大小周调休？
- 面试官在面试中的言行本身就是样本（见下）

**4. 业务健康**
- 最近一轮融资时间与账上现金（创业公司）
- 业务线在大厂内是核心还是边缘（边缘线 = 裁员先裁）
- 负面新闻：断臂求生、高管离职潮

## 信源优先级与交叉验证

熟人内推打听 > 脉脉职言（认证员工）> 看准网 > 小红书/知乎个体叙事 > 官方宣传（权重最低）

规则：单一差评不下结论；**找 3 个相互独立的信源**；区分「个例吐槽」vs「系统性问题」；最近 6 个月的信息权重高于两年前。

## 面试现场的验证问题（礼貌版探针）

- 「团队的工作节奏大概是什么样的？」→ 听对方给具体例子还是打太极
- 「周末一般需要处理工作吗？上一次是什么时候？」
- 「团队最近一次团建/outing 是什么活动？」→ 听活动形态是否健康
- 观察面试官本人：开不当玩笑？对女性候选人的态度？办公区氛围（路过时看工位状态、下班时间点）

## 红旗清单（出现即降级）

- 「我们团队像家人一样」（边界模糊文化的经典话术）
- 「弹性工作制」但说不清几点下班（≈无限加班）
- 面试官言行轻浮、开性别相关玩笑
- HR 回避双休/加班问题，或反问「你能接受加班吧」当默认项
- 脉脉大量「氛围压抑」「领导 PUA」且时间集中
- 有骚扰通报/诉讼实锤 → **直接 D**

## 绿旗清单

- 明确说「不鼓励无意义加班」「周末基本不用看消息」且能举具体例子
- 有成文的 anti-harassment 制度且 HR 能正面回答
- 离职员工口碑中性偏正（全是狂热好评反而可疑）

## 评级与联动

- **A** 四维全绿 → targets.md 优先级置顶
- **B** 小瑕疵（如加班有调休、无前科）→ 正常推进
- **C** 有系统性疑点但无实锤 → 推进但面试探针加强
- **D** 骚扰前科/严重违法/风气实锤 → 从 targets.md 剔除，告知用户原因
